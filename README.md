# INSIDE LIFE React Project

A Vite + React project demonstrating a student profile, inline-styled navigation bar, reusable user cards, and a team members page.

## Requirements
- Node.js 18+ and npm

## Run locally
```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Project structure
```text
src/
  components/
    Navbar.jsx
    StudentProfile.jsx
    UserCard.jsx
    UserCard.css
    TeamMember.jsx
    TeamMembers.css
  App.jsx
  App.css
  main.jsx
```

## GitHub
After confirming `npm run build` succeeds, create an empty repository on GitHub and run:
```bash
git init
git add .
git commit -m "Build React student profile and team page"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```
Replace the remote URL with your own repository URL.
